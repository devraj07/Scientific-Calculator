# Scientific Calculator (Web App)

A simple **scientific calculator** built using **HTML, CSS, and JavaScript**.

## Features

- Basic operations: `+`, `-`, `×`, `÷`, parentheses
- Scientific functions:
  - `sin`, `cos`, `tan` (radians)
  - `log` (base 10)
  - `ln` (natural log)
  - `√` (square root)
  - `xʸ` (power)
  - `π`
- Clear (`C`) and Delete (`DEL`)
- Works on desktop and mobile browsers
- Keyboard support for numbers and basic operators
